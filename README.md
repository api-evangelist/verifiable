Verifiable is an API-first provider network management and credentialing platform for healthcare. Its RESTful API lets health plans, credentialing vendors, and digital health companies programmatically manage provider and facility records, run real-time primary-source verifications of licenses and credentials, continuously monitor providers for sanctions and exclusions, scan reference datasets, manage payers, payer plans, groups, and provider enrollments, drive credentialing requests, and receive events via webhooks. The platform is built API-first (Verifiable builds its own product on the same API) and is used as underlying credentialing infrastructure across healthcare. Backed by Craft Ventures.

**Areas:** Company · Health · Healthcare · Credentialing · Provider Data · Primary Source Verification · Compliance · Monitoring

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Verifiable: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
